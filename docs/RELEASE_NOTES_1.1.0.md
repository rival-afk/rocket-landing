# Rocket Landing 1.1.0

## Новое

- **Меню**: при обычном запуске игра стартует с меню «Играть / TAS».
  TAS-экран даёт: расчёт идеального забега перебором всех комбинаций ввода
  (60 Гц), остановка с сохранением в `user://tas.json`, загрузка готовой
  ленты из файла, проверка воспроизведением в игре с выдачей вердикта
  (PASS/FAIL + тик касания стены).
- **Сенсорное управление** (только Android): кнопки ◀ ▶ и «ТЯГА» на экране.
- **Улучшен TAS**: вместо одной выбранной «лучшей» ветви — параллельный
  поиск лучом (beam) по двум дорожкам: GPU-compute шейдер (если устройство
  умеет локальный Vulkan RenderingDevice) + CPU-поток с более широким лучом.
  Проверка пересечений со стеной — по 9 точкам повёрнутого прямоугольника
  ракеты с запасом 2 px. Цель — лучший рекорд (глубина) и время.
- **API-запуск без меню**: флаг `--api`; кроме того, любой запрос к API
  автоматически закрывает меню и снимает паузу — тренажёры продолжают
  работать как раньше.
- Solo-смерть при активном TAS не перезагружает сцену (иначе проверка не
  успевала бы показать результат).

## Исправления

- Игра запускается и с пустым `.godot/` после первого `--import`
  (раньше падала в цикл «crash → reload» без импорта).

## Установка

- **Windows**: `RocketLanding.exe` + `RocketLanding.pck` рядом.
- **Linux (Debian)**: `RocketLanding-linux-x86_64.tar.gz` — распаковать,
  `chmod +x RocketLanding`.
- **Android**: `RocketLanding.apk` (arm64-v8a, debug-подпись; включить
  установку из неизвестных источников).
